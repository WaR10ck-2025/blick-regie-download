# Blick-Regie – Test-App herunterladen

Dies ist der Download-Bereich der **Blick-Regie** für Windows. Hier liegt nur das fertige Installationsprogramm – kein Quelltext.

Die Blick-Regie schaltet in OBS live zwischen deinen Kameras um: per Wisch zur Seite, später auch per Blick. Sie läuft komplett offline – kein Kamerabild verlässt deinen PC.

> **Stand:** Prototyp zum Testen. Die aktuelle Fassung und ihre Neuerungen stehen unter [Releases](https://github.com/WaR10ck-2025/blick-regie-download/releases).

## Herunterladen

**Neueste Version:** https://github.com/WaR10ck-2025/blick-regie-download/releases/latest/download/Blick-Regie-Einrichtung.exe

**Prüfsumme (zum Vergleichen):** https://github.com/WaR10ck-2025/blick-regie-download/releases/latest/download/Blick-Regie-Einrichtung.exe.sha256

## So geht's

1. `Blick-Regie-Einrichtung.exe` herunterladen und starten. Sie braucht keine Adminrechte und installiert nur für dich. Weil das Programm nicht von Microsoft signiert ist, warnt Windows einmal: „Weitere Informationen“ → „Trotzdem ausführen“.
2. OBS Studio ab Version 30 starten. Für den Test am besten ein **eigenes, portables Test-OBS** nehmen – dann ändert sich an deinem normalen OBS nichts.
3. Die Blick-Regie zeigt dir die nächsten Schritte: Fernsteuerung in OBS einschalten, für jede Kamera eine Szene anlegen.

Die App hält sich danach selbst aktuell.

## Entfernen

Windows-Einstellungen → Apps → „Blick-Regie“ → Deinstallieren. Dabei verschwinden auch ihre Einstellungen.
